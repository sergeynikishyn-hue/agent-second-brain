# Задачи штаба продвижения

Заведено 19.08.2026 решением Сергея: Никита становится каналом для задач и
вопросов штаба продвижения (реклама, сайт, контент), технические аварии
остаются в своих ботах (Директ, сайт, SEO) и через этот навык не идут.

## Источник данных

Реестр задач штаба - `prodvizhenie/zadachi.md` в `/home/brain/claude-vault`
(это чужой git-репозиторий, штаб ведёт его сам). Перед чтением обнови копию:

```bash
cd /home/brain/claude-vault && git pull -q --rebase --autostash
```

Файл только читать, не редактировать и не коммитить в этот репозиторий -
туда же пишет автоматика штаба, параллельная запись столкнётся с ней.

## Задача 1: просроченные и сегодняшние задачи

В файле раздел «Открытые» - таблица со столбцами Что / Кто / Срок / Признак
готовности / Статус. Найди строки, где Срок сегодня или раньше, а статус не
`сделано` и не `снято`. Если такие есть - сообщи коротко: что, для кого срок,
на сколько дней просрочено. Если ничего нет - ответ должен начинаться со
строки `[SILENT]` (это мониторинговая задача, пустой список слать не нужно).

## Задача 2: понедельничные числа для weekly-review

Штаб продвижения каждый понедельник в 09:30 присылает Сергею (через отдельное
плановое задание) вопрос: сколько состоялось разборов/встреч за неделю,
сколько подписано сделок, и попадает ли каждый клиент в портрет (выручка от
20 млн ₽/мес). Это задание запускается отдельно около 09:58, чтобы забрать
ответ перед понедельничным разбором в 10:00.

Определи сегодняшнюю дату (`date +%Y-%m-%d`), открой свой
`daily/<дата>.md`, найди среди сообщений после 09:30 ответ Сергея с числами
(короткое сообщение вида «разборов 3, сделок 1» или похожее по смыслу). Если
нашёл - создай (или перезапиши) файл `/home/brain/nikita-otvety/razbory-nedeli.md`
(директорию создать, если её нет) в формате:

```
Дата: <сегодняшняя дата>
Разборов: <число>
Сделок: <число>
Портрет: <короткое пояснение, если Сергей его дал>
```

Файл перезаписывается каждую неделю заново, история не нужна - она остаётся в
`daily/`. Если ответа ещё нет к моменту запуска - ничего не создавай и не
трогай существующий файл, ответ начни строкой `[SILENT]`.

пушей в `claude-vault` не делать. Если что-то в реестре задач непонятно или
выглядит противоречиво - просто перескажи как есть, не додумывай и не
интерпретируй за штаб.
