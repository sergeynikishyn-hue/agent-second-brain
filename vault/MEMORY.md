### Продающие сообщения — стоп-фразы (не использовать)
- «деньги вроде есть» — забанено пользователем 2026-08-01, без указанной причины (штамп/клише в копирайтинге). Заменять на конкретику про механику проблемы (комиссии/кассовые разрывы и т.п.) без общих фраз о деньгах.
- «Настрою [услугу]» (обещание в 1-м лице будущего времени) — звучит рекламно (2026-08-01). Заменять на констатацию факта: «такие работы есть в портфеле», «есть опыт по ДДС/ОПиУ/балансу для маркетплейсов» — говорить как о готовом кейсе/факте, не как о предложении-питче. Рабочий вариант, утверждённый пользователем: «Я занимаюсь внедрением управленческого учёта для собственников бизнеса» (описание профессии/факта, не персональное обещание для этого лида).
- «Спасибо за запрос» / «спасибо за заявку» — забанено 01.09: режет слух. Первое сообщение лиду начинается сразу с дела, без благодарственного зачина.
- «в цифре за период не видно, где и когда ломается» — плохая фраза (01.09). Рабочая замена: «в общей цифре за период слабые месяцы прячутся за сильными».
- В финале сообщения лиду не гадать дату звонка — спрашивать открытым вопросом «Когда вам будет удобно созвониться?» вместо предложения конкретного слота (пользователь сам решил так в финальной версии 2026-08-01, это снимает проблему незнания календаря лида).
